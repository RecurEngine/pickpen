# Pickpen Sync

Pickpen Sync 是一款本地优先的 Obsidian 云同步插件。

## 主要功能

- 在桌面端和移动端之间同步 Vault 文件，自动检测本地及远端改动。
- 中国网络友好：服务面向国内网络环境优化，无需额外网络工具即可使用。
- 两端修改同一篇笔记时先做行级自动合并，只有真正改到同一处才保留冲突副本，双方内容都不会丢。
- 待处理的冲突会在同步回执、Ribbon 提示与设置页状态卡片上提示，并可一键跳转。
- 查看和恢复单个文件的历史版本。
- 一个账号可管理多个远端仓库。
- 按仓库选择开启端到端加密：内容在本机加密后再上传，服务端只保存密文；仓库密码不上传、不与账号绑定。
- 本地 Obsidian Vault 始终保留可直接使用的工作副本。

## 重要服务与数据说明

- 使用 Pickpen Sync 必须登录账号，邮箱验证码用于登录和注册。
- 未开启加密的仓库在服务端以明文存储；开启端到端加密后，服务端只保存密文。仓库密码不会离开你的设备，也不与账号绑定——忘记密码后内容无法被任何人恢复，包括我们。
- 服务提供有额度限制的免费方案；付费方案可获得更多存储空间与能力，具体条款以[官网价格页](https://www.pickpen.net/pricing)和结账页为准。
- 打开“关于与反馈”区域时，插件会从 `rrecurengine.com` 加载客服二维码图片。
- 插件不含客户端统计分析、广告、行为追踪或自更新代码。发生未捕获异常或同步/网络失败时，默认发送最小化的错误诊断信息（不含文件内容、文件名、仓库名、邮箱或令牌），可在“设置 → 诊断”中关闭，诊断信息最长保留 90 天。点击“邮件反馈”只会在本地生成邮件草稿，发送前可自行检查或删除。

完整的数据处理说明见[隐私政策](PRIVACY.md)。
